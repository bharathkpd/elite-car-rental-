# Elite Car Rentals - Premium Mobility 🏎️

Elite Car Rentals is a high-performance, mobile-optimized car rental platform designed for a seamless, "app-like" user experience. Inspired by modern mobility leaders like Uber and Rapido, the platform features a bold Black, White, and Energetic Yellow aesthetic.

## 🚀 Live Demo
**[View Live Website](https://bharathkpd.github.io/elite-car-rental-/)**

## ✨ Key Features
- **App-Like Design:** Mobile-first, immersive interface with smooth transitions and glassmorphism elements.
- **Dynamic Fleet Presentation:** Horizontal touch-friendly carousels for easy vehicle browsing.
- **Real-Time Price Calculation:** Instant rental estimates based on daily rates and trip duration.
- **Direct WhatsApp Booking:** Seamless transition from browsing to booking via integrated WhatsApp messaging.
- **Premium Branding:** High-contrast logo with iconic BMW-style elements and "Lights On" effects.
- **FAQ Support:** Integrated section covering documentation, deposits, and delivery.

## 🛠️ Technology Stack
- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom design system with Scroll Snap, Flexbox, and Grid.
- **JavaScript:** Logic for price calculation, UI animations, and navigation.
- **FontAwesome:** Premium racing and mobility icons.

## 📱 Mobile Experience
The platform is specifically engineered for mobile thumb-navigation, featuring:
- A dedicated side-drawer menu.
- Bottom-tab navigation for quick actions.
- Optimized touch targets for booking and support.
